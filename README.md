# Curve Sketch Drill

Practice app for curve-sketching questions in Oxbridge engineering interviews.

Open `index.html` in a browser (works best in Safari on iPad with Apple Pencil, or any desktop browser).

## Features
- 750 distinct questions: 250 each at Easy, Medium and Hard, plus 49 hand-written interview-style questions (Gravell sheet and Oxbridge interview lists).
- No repeats until you have done every question at a level.
- Blank dotted sheet that you can pan and zoom without limit. Turn axes on when you want them (integers, radians or degrees, with a range picker for trig).
- Apple Pencil only drawing on iPad; fingers move and zoom the sheet.
- Hold the pen still at the end of a stroke to straighten it.
- Detects hand-drawn axes and lines the answer up with your origin.
- Reveal shows the true graph with Desmos-style points of interest, hover/tap tracing and pinned labels, plus exact values for turning points (for example (1/e, e^(−1/e))).
- Switch between your sketch and the answer.
- Question bank page (all questions) and My saved page (came up / starred), each with an answer preview.
- Copy-to-Desmos for every question.

Progress (history, stars, ratings) is stored in the browser you use.

## Run it full screen on iPad
1. Make this repo public and turn on GitHub Pages (Settings → Pages → Deploy from a branch → `main`, `/ (root)`).
2. Open `https://durunkim.github.io/curve-sketch-drill/` in Safari.
3. Share → Add to Home Screen. Open it from the Home Screen icon: it runs full screen with no Safari bars.
